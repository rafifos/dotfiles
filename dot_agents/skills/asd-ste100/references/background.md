# ASD-STE100 Background: History, Governance, Adoption, Training, Tools

Load this file for questions ABOUT the standard (its history, who maintains it, training, tools, misconceptions) rather than for writing or checking STE text.

## Definition

ASD-STE100 Simplified Technical English (STE) is a controlled natural language (CNL) and international standard for technical documentation, fully owned by ASD (Aerospace, Security and Defence Industries Association of Europe), Brussels. EU Trade Mark No. 017966390.

- Current version: **Issue 9, released January 15, 2025**; Issue 10 scheduled for January 2028 (new issues roughly every 3 years, driven by user change forms)
- Two parts: Writing Rules (Part 1, 53 rules in 9 sections) + Controlled Dictionary (Part 2, ~900 approved words)
- Free download (since Issue 6, 2013) via a form at **asd-ste100.org**

## Historical Timeline

| Year | Event |
|---|---|
| Late 1970s | European airlines request a standardized English for maintenance docs (80% of European airlines were not from English-speaking countries) |
| 1979 | Project starts; AEA approaches AECMA |
| 1981 | AECMA develops its own controlled language; American aerospace (AIA) invited |
| June 30, 1983 | SEWG (Simplified English Working Group) established at the Fokker plant, Schiphol |
| 1986 | First release (AECMA Simplified English Guide); becomes a requirement for ATA 100 / ATA 104 |
| 2004 | AECMA merges into ASD; renamed ASD Simplified Technical English, Specification ASD-STE100 |
| 2006 | EU Trade Mark granted (renewed 2018) |
| 2013 (Issue 6) | Becomes free of charge |
| 2025 (Issue 9) | Transitions from specification to international **standard**; subtitle becomes "Standard for Technical Documentation" |

17 total releases; 90+ working meetings across 13 countries. ~19,000 copies of Issues 6–8 distributed; ~1,000 of Issue 9 by March 2025.

## Issue 9 Key Changes (2025)

- Title changed from "Specification" to "Standard for Technical Documentation"
- More than half of the 53 writing rules refined for clarity
- 555 dictionary entries updated for linguistic precision
- Terminology modernized per ISO 1087-1:2019; subject-field classifications expanded
- Dictionary streamlined for writers/translators; aligned with international standards

## Governance

**STEMG (Simplified Technical English Maintenance Group)** develops, publishes, and maintains the standard. Formed 1983 as SEWG, renamed 2004. Meets twice a year. 12 Members (ASD countries) + 10 Partners (non-ASD countries). Reports to the ASD Product Support Specifications Group (PSSG) and Services Commission (SVC).

- Chair: Orlando Chiarello (Italy, Secondo Mona); Vice Chair: Jennifer Bennor (Germany, Vestas) — as of Issue 9
- **STEST** (STE Support Teams): 8 national/multi-country teams — FRC (French), GEC (German), IT (Italy), NC (Nordic), POC (Portuguese), SPC (Spanish), UK, US
- **AITT** (AI Task Team): one expert per STEST + a STEMG representative; monitors AI tool evolution relative to STE

Change process: users submit STEMG change forms → STEMG reviews and debates → approved changes enter the next issue.

## Training and Certification

STE requires strong English proficiency plus technical knowledge — recommended minimum **CEFR C1** (≈ IELTS 7.0–8.0, TOEFL iBT 95–110). Untrained writers tend to focus only on the dictionary and ignore the rules.

Only two accredited training routes (ASD/STEMG endorse no others):

1. **STEMG Members/Partners** — basic certified training
2. **UNINETTUNO University** (ASD-authorized) — basic training AND train-the-trainer

| Course | Details |
|---|---|
| Basic (technical writers) | 9 video lessons + exercises, online, self-paced; all 9 STE sections; assessment = exercises 60% + final exam 40%; certificate on passing |
| Train-the-trainer | 8 weeks online; requires basic course + 12 months experience; adds 4 teaching-methodology lessons; graduates can deliver (not certify) STE training |

## Tools Landscape

**ASD/STEMG do NOT endorse, certify, or authorize any tools.** Tools are optional aids, not substitutes for the standard or for knowledge.

| Tool type | Function | Limitation |
|---|---|---|
| AI-based tools | Highlight non-compliant text, suggest corrections | Variable accuracy; privacy risks; may not reflect standard intent |
| Word and rule checkers | Flag unapproved words, detect rule violations | Need company glossary integration; generate noise |
| Word checkers only | Dictionary-based validation | "Unknown word" alerts without a glossary |
| Look-up tools | Electronic search of rules/dictionary | No interactive validation |

Known (not endorsed) tools: BSEC (Boeing Simplified English Checker, 350+ rule parser), HyperSTE (Etteplan), Congree STE Checker, TechScribe Term Checker.

Caveats: no tool can write STE or convert non-STE text accurately; all tools produce false positives and negatives; human judgment is always required; final approval rests with the writer.

## Common Misconceptions

| Misconception | Reality |
|---|---|
| "STE is baby English" | It is a precise, structured standard for complex systems |
| "Only for non-native speakers" | Also improves communication among native speakers |
| "Eliminates translation" | Only if readers have basic English; otherwise translation is easier, not eliminated |
| "Changes technical meaning" | Correct use preserves exact meaning |
| "Usable for oral communication" | Documentation only |
| "Readers need STE training" | No — it is a subset of English; only writers train |
| "STE can teach English" | It requires high English fluency already |
| "Replaces a style guide" | Must be used WITH style guides and other specifications |
| "Anyone can use the STE logo" | EU Trade Mark strictly protected |
